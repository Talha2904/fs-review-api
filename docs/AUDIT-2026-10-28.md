# Audit of Phases 0 to 6

Date: 28 October 2026 · Fixes verified: 29 October 2026

## Scope and method

Three reviewers read the api independently, each on one area, without being told what the authors expected
to find:

1. Identity, security and the HTTP layer (Phases 0 and 1).
2. The review workflow: entities, engagements, documents, workflow, points, checklist, sign-off, reports and
   the snapshots (Phases 2 to 4), including how the web app's store uses them.
3. Billing on tables, the server analysis jobs, and the fidelity of the TypeScript port of the analysis engine
   against the frozen browser engine, which a sub-reviewer fuzzed (Phases 5 and 6).

Each finding was checked against the code before it was fixed. Every fix has a regression test, listed in
the last column. Line references are to the code as it was on 28 October.

Severity: **Critical**: a control can be bypassed or data lost in normal use. **High**: a role sees or changes
what it must not, or a hostile input harms the service. **Medium**: wrong results under concurrency or edge
cases. **Low**: hardening and hygiene.

## Found during the live check after the fixes

- The api's file watcher does not reload the `shared` package, so a stale build answered every review request
  with 403 until the api was restarted. Noted in the development notes: restart the api after rebuilding `shared`.
- The web app showed "Not analysed" when the listing's light copy of a fund (without the run's result) arrived
  before the full one. Fixed in `App.jsx`.
- Started from the parent folder, the reading process could not resolve `tsx` by name. Fixed by passing its
  absolute path.

## Outstanding

- SheetJS 0.20.3 (B3) needs the owner's approval to install from the SheetJS CDN.
- Visibility by team (a reviewer sees only their own funds) is not implemented: every member of the review staff
  sees every fund, as the web app always did. A decision for the owner.
- `/api/events` sends every fund's change ids to every member of the review staff (ids and job status only).
